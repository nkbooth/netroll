# Nets

A *net definition* is the reusable description of your net: what it is, where it runs, when it
runs, and who owns it. This section covers everything you set up before the net goes live.
Running the net itself is in [live sessions](../live-sessions/index.md).

## Guides

- **[Create a net](create-a-net.md)** — the full field set, from band and mode to repeater tone
  and net type.
- **[Schedule a net](schedule-a-net.md)** — one-off and recurring occurrences, timezone-aware.
- **[Manage owners](manage-owners.md)** — add co-owners so the net outlives a single account.
- **[Configure delivery](configure-delivery.md)** — email, webhook and Discord targets for the summary
  sent when a session closes.
